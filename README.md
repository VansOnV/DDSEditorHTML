# DDSEditorHTML
A DDS Editor &amp; Converter for Game Textures etc.

How to Use:

Install the .html and open it (offline support) or use the web/github pages version.

https://vansonv.github.io/DDSEditorHTML/




## DDS Editor v1.5 by Me!

***Features***

- Batch Processing
- Batch Resizing
- Batch Upscaler
- Smart Resizer (Has batch support)
- Select a whole folder containing images
- Supports converting to DXT1, DXT3, DXT5, BC7, A8, L8, A8R8B8G8, A1R5G5B5, ATI1, ATI2 DDS Formats!
- Auto convert A8R8G8B8 textures to DXT1 or DXT5 (optional)
- Supports converting DDS<>PNG<>JPEG
- Image Resizer + Size Presets
- Image Editor
- Image Upscaler
- Mipmap Levels + Mipmap Level Presets
- Output to folder/Output Source
- Keeps Original Filename when exporting.
- Preview for imported images
- **Fully Offline!** 

***Compatability*** 

- All platforms
- For iOS, you will need an app called “Texstastic Code Editor” and run the HTML on Safari using that app. Or use the Web Version!

***Usage***

- Just click on the file and it should open your browser and load the editor/converter directly.
- Just select an image file (dds, png, jpeg). Select option for dxt format or export to png or jpeg, select option for size or use original, select option for mipmap levels or use original.
