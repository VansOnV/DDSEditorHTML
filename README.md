# DDSEditorHTML
A DDS Editor &amp; Converter for Game Textures etc.

How to Use:

Install the .html and open it (offline support) or use the web/github pages version.

https://vansonv.github.io/DDSEditorHTML/


## DDS Editor v1.7 Final (Maybe)
 

***Features***

- Batch Processing
- Batch Resizing
- Multi-folder support
- DDS Formats: DXT1, DXT3, DXT5, BC7, ATI1, ATI2,      A8, L8, A8R8G8B8, A1R1G1B1.
- Supports Image Formats: .dds, .png, .jpeg, .tga, .svg, .bmp
- Supports converting DDS<>PNG<>JPEG
- Image Resizer + Size Presets + Keep Aspect Ratio
- Mipmap Levels + Mipmap Level Presets + Automatic Mipmap Level Generator
- Upscaler
- Custom Configuration Settings (import, export)
- Photo Adjustments
- Custom Output Source
- Keeps Original Filename/Overwrite 
- Preview for imported images
- Dark Mode/Light Mode
- **Fully Offline!** 

***Compatability*** 

- All platforms (Windows, Mac, Linux, iOS, Android)
- For iOS though, you need to use a code editor/runner or you can use the Web Version below!

***Usage***

- Just click on the file and it should open your browser and load the editor/converter directly.
- Just select an image file (dds, png, jpeg). Select option for dxt format or export to png or jpeg, select option for size or use original, select option for mipmap levels or use original.

***Q&A***

What is the purpose of this tool?
- **It is for converting, editing, or modifying images, specifically targetting game textures (.dds) for multiple games like GTA 5 which use .dds textures.**

Will this be the final version?
- ** Maybe, I dont see anymore things to add or refine in this new version. I love it, the new UI design is clean and matches today's aesthetics, the animations, everything works flawlessly. **

How can I use it?
- **You can import your textures/images (.dds, .png, .jpeg) and edit them to your needs.**

What does "Keep Aspect Ratio (Recommended For Batch Resizing) do?
- **I recommend you always have this feature turned on when batch resizing multiple textures. There are textures that arent even, something like 512x256, or 2048x1024, they arent the same size, yes. And then lets say you want to batch resize all textures to 512x512, if you do so, their aspect ratio will be ruined, the texture will not work properly. With this feature turned on instead, it fixed that problem, allowing you to batch resize uneven and even textures to a smaller size.**
